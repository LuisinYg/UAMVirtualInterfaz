
# UAMVirtual - Sistema de Videoconferencias Académicas

Este proyecto es el sistema de videoconferencias institucional para la Universidad Autónoma Metropolitana (UAM), diseñado para ofrecer una experiencia de comunicación segura, fluida y adaptada al entorno académico.

## 🚀 Cómo ejecutar la aplicación

### 1. Requisitos previos
Asegúrate de tener instalado **Node.js** (Versión 18 o superior).

### 2. Instalación de dependencias
Desde la carpeta raíz del proyecto, ejecuta:
```bash
npm install
```

### 3. Iniciar el servidor de desarrollo
Ejecuta el siguiente comando:
```bash
npm run dev
```

### 4. Acceso
La aplicación estará disponible en:
**[http://localhost:9002](http://localhost:9002)**

---

## 🛠️ Stack Tecnológico
- **Frontend**: Next.js 15 (App Router), React, TypeScript.
- **Estilos**: Tailwind CSS, ShadCN UI.
- **Animaciones**: Framer Motion.
- **Backend**: Preparado para integración con Firebase (Auth y Firestore).
